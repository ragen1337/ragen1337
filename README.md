### What I'm working on

**[LookSee](https://github.com/okoflow/looksee)** is our main product. It's self-hosted video analytics: you connect your cameras, build a small workflow in a visual editor (which model to run, which zone to watch, what to do when something shows up), and it all runs on your own hardware. Object detection runs on ONNX. [Website](https://looksee.okoflow.com), [docs](https://github.com/okoflow/looksee-docs).

**[rust-realtime-analytics](https://github.com/ragen1337/rust-realtime-analytics)** is a pet project where I wanted to see how far Kafka and ClickHouse go on a single laptop. The answer was about 5,000 events a second with a p99 under 10 ms, without losing a single event.
